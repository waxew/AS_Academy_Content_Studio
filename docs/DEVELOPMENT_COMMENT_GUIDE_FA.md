# راهنمای کامنت‌گذاری توسعه AS Academy Content Studio

## هدف

این سند استاندارد توضیح‌نویسی کد در پروژه را مشخص می‌کند.

## قوانین کامنت

هر فایل مهم باید توضیح دهد:

1. این فایل چه مسئولیتی دارد؟
2. در معماری AS Academy چه نقشی دارد؟
3. چه چیزهایی نباید داخل آن قرار بگیرد؟
4. وابستگی‌های آن چیست؟

## استاندارد کلاس‌ها

قبل از کلاس‌های اصلی توضیح داده شود:

- هدف کلاس
- ورودی و خروجی
- ارتباط با سایر لایه‌ها

## استاندارد توابع

برای توابع مهم:

- هدف تابع
- پارامترها
- نتیجه
- خطاهای احتمالی

## قوانین معماری

Content Studio:

مجاز:
- مدیریت محتوا
- ساختاردهی دانش
- تولید Package

غیرمجاز:
- UI Logic
- Database Runtime
- Navigation
- Business Logic اجرایی

## زبان توضیحات

توضیحات توسعه باید فارسی و قابل فهم برای توسعه‌دهنده آینده باشد.
