# AS Academy Basic

## معرفی

این بخش محتوای پایه AS Academy است. هدف آن ایجاد دانش مشترک قبل از ورود به مسیرهای تخصصی مانند Java، Python، Android، Automotive و AI است.

## مسیر آموزشی

### 01 - Computer Fundamentals
- آشنایی با کامپیوتر
- Hardware و Software
- سیستم‌عامل
- فایل و Storage

### 02 - Programming Fundamentals
- تفکر الگوریتمی
- حل مسئله
- Variable
- Data Type
- Condition
- Loop
- Function

### 03 - Software Engineering Basics
- چرخه تولید نرم‌افزار
- Git و Version Control
- تست نرم‌افزار
- مستندسازی

### 04 - Web Fundamentals
- Internet
- Client / Server
- HTTP
- API
- Database Basics

### 05 - Database Fundamentals
- Database Concepts
- Table
- Relation
- SQL Basics

### 06 - Networking Fundamentals
- IP
- DNS
- TCP/IP
- Network Basics

### 07 - Security Fundamentals
- Authentication
- Authorization
- Encryption
- Secure Coding Basics

## سطح‌بندی محتوا

تمام مباحث طبق استاندارد AS Academy در چهار سطح ارائه می‌شوند:

- Fundamentals (مبانی)
- Beginner (مقدماتی)
- Advanced (پیشرفته)
- Expert (تخصصی)

هر موضوع شامل:

- Chapter
- Lesson
- Exercise
- Quiz
- Project

خواهد بود.
